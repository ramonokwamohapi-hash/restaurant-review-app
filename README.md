# 🍽️ FlavorFinder - Restaurant Review Platform

A full-stack web application for discovering and reviewing restaurants worldwide.

## 🌟 Features

- **🌍 Worldwide Restaurant Search** - Discover restaurants from around the world
- **⭐ Complete Review System** - Rate and review with detailed categories
- **✏️ Edit/Delete Reviews** - Full CRUD operations for user reviews
- **🔐 User Authentication** - Secure login/register system
- **❤️ Favorites System** - Save your favorite restaurants
- **🔍 Advanced Search & Filtering** - Find exactly what you're looking for
- **📱 Fully Responsive** - Works perfectly on all devices
- **🎨 Modern UI** - Beautiful Bootstrap interface

## 🚀 Live Demo

**Live Application**: [https://restaurant-app-12e16.web.app](https://restaurant-app-12e16.web.app)

## 🛠️ Technology Stack

- **Frontend**: React, Bootstrap, CSS
- **Backend**: Firebase (Firestore, Authentication)
- **Deployment**: Firebase Hosting
- **External APIs**: Worldwide restaurant data integration

## 📦 Installation

\`\`\`bash
# Clone the repository
git clone https://github.com/ramonokwamohapi-hash/Restaurant-review-app.git

# Navigate to project
cd Restaurant-review-app/frontend

# Install dependencies
npm install

# Start development server
npm start
\`\`\`
